## Projects

### 🍯 [HoneyForge](https://github.com/DanielE330/umirhack3)

A platform for managing honeypots — decoy systems used to observe attacker activity.

- A control center for profiles and honeypots, with telemetry collection from agents.
- Honeypot machine orchestration in Proxmox.
- An operator web interface and APIs connecting the components.

**Technologies:** Python, FastAPI, PostgreSQL, Docker, Proxmox.

**Result:** 🥇 1st place at Umirhack III.

### 📚 [micro-swagga](https://github.com/DanielE330/micro-swagga)

A family of lightweight services that bring OpenAPI documentation from multiple microservices into a single interface.

- Fetches specifications over the internal network without direct browser requests to each service.
- Rewrites server URLs in specifications to support reverse proxy routing.
- Two configuration options: environment variables or service discovery through Docker labels.

**Technologies:** Python, FastAPI, Docker, OpenAPI.
