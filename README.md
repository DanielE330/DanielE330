## Обо мне

Разрабатываю бэкенды на Python, приложения на Flutter и инфраструктуру для их запуска. В проектах работаю с API, базами данных, контейнеризацией и развёртыванием сервисов.

Участвую в хакатонах, в том числе в роли капитана команды. Беру на себя разработку, настройку окружения и подготовку проекта к демонстрации.

- 🐍 **Backend:** API и сервисы на Python и FastAPI.
- 📱 **Приложения:** интерфейсы на Flutter и Dart, настольные приложения на C++ и Qt.
- 🐳 **Инфраструктура:** Docker, CachyOS и управление окружением в Proxmox.
- 🤝 **Командная работа:** координация разработки и интеграция компонентов проекта.

## Проекты

### 🍯 [HoneyForge](https://github.com/DanielE330/umirhack3)

Платформа управления honeypot — ловушками для наблюдения за действиями атакующих.

- Центр управления профилями и ловушками, сбор телеметрии от агентов.
- Оркестрация машин-ловушек в Proxmox.
- Веб-интерфейс оператора и API для взаимодействия компонентов.

**Технологии:** Python, FastAPI, PostgreSQL, Docker, Proxmox.

**Результат:** 🥇 1 место на Umirhack III.

### 📚 [micro-swagga](https://github.com/DanielE330/micro-swagga)

Семейство лёгких сервисов для объединения OpenAPI-документации микросервисов в единый интерфейс.

- Получение спецификаций через внутреннюю сеть без прямых запросов браузера к каждому сервису.
- Подмена адресов серверов в спецификациях для работы через reverse proxy.
- Два варианта настройки: переменные окружения или обнаружение сервисов по Docker labels.

**Технологии:** Python, FastAPI, Docker, OpenAPI.
